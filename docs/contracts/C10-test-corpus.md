# C10 — Synthetic test corpus

The corpus is the end-to-end arbiter. Ground truth is generated by the **same** C9 forward model that the fitter uses (no independent renderer). Extraction (C1A) still runs on rendered full images so centroid/background error is in the loop.

## C10.1 Standard camera (frozen)

Used unless a scenario overrides a named field.

| Quantity | Value |
|---|---|
| `n_row`, `n_col` | 512, 512 |
| `wavelength_m` | \(550\times 10^{-9}\) |
| `pupil_diameter_m` | 0.20 |
| `focal_length_m` | 2.00 |
| `pixel_scale_arcsec` | 0.50 |
| `optical_axis_pixel` | (255.5, 255.5) |
| `gain_e_per_adu` | 1.5 |
| `read_noise_e` | 5.0 |
| `saturation_adu` | 60000 |
| `exptime_s` | 30.0 |
| `known_defocus_waves` | 0 |
| `n_pupil` | 256 |
| `n_fft` | 1024 |
| `stamp_size` | 31 |
| `expected_fwhm_px` | 2.8 |

Plate-scale consistency: `pixel_size_m` SHALL be set to \(f \cdot \mathrm{pixel\_scale\_rad}\) so C1.4.1 \(\delta=0\).

## C10.2 Image rendering

1. Draw a list of true star positions (C10.3).
2. For each star, compute true local \(a_k(x,y)\) from the scenario’s **true field maps** (polynomials of the same form as C3.3).
3. `forward_psf` with true \(\theta\), `flux` = true electrons / gain converted to ADU, `sky=0` on the stamp; then **insert** the stamp into the full image by adding (not replacing) onto a canvas that already has a **flat sky** of `sky_adu` (scenario default 100 ADU) plus i.i.d. Gaussian read noise and Poisson (C1A.9 inverse): for each pixel, draw Poisson(\(\max(\mathrm{gain}\cdot \mathrm{true\_adu}, 0)\)) / gain, then this already includes Poisson; **do not** also add the CCD equation twice. Frozen noise: `rng` from `seed`, Poisson via `u64` conversion of λ rounded to nearest integer then Knuth, or `rand_distr::Poisson` — **frozen crate `rand` 0.8 + `rand_distr`**, seed `SeedableRng` `StdRng`.
4. Saturated pixels clip at `saturation_adu`.

Stars closer than `1.5 * expected_fwhm_px` SHALL NOT be generated (corpus isolation).

## C10.3 Scenarios

Each scenario has `scenario_id`, `seed`, true maps, `n_stars`, true kernel globals.

### C10.3.1 `unaberrated`

- All \(a_k=0\), no kernels except charge_diffusion σ=0.3 px true.
- 80 stars, uniform random in a margin of 40 px from edges, `seed=1`.
- Purpose: Airy recovery, Jacobian harness, extraction SNR.

### C10.3.2 `single_defocus_const`

- \(a_{2,0}=0.35\) waves, constant field; all other a=0; diffusion 0.3.
- 80 stars, `seed=2`.
- **Sign:** truth is **positive**. Init is also positive. Recovery test is on **algebraic** \(a_{2,0}\), not absolute value.

### C10.3.3 `single_defocus_neg`

- \(a_{2,0}=-0.35\). Same else, `seed=3`.
- Recovery: `| |â| - 0.35 |` within tolerance **and** `defocus_sign_ambiguous=true`. The algebraic sign MAY be wrong; the corpus scorer SHALL pass if `|â + 0.35| < tol` **or** `|â - 0.35| < tol`. This is the only scenario with an absolute-value clause.

### C10.3.4 `single_coma_linear`

- \(a_{3,1}(u,v) = 0.15 + 0.25 u\), \(a_{3,-1}=0\), others 0, `seed=4`, 100 stars.
- Tests centroid-preserving coma + stage-2 linear map.

### C10.3.5 `defocus_plane` (sensor tilt)

- \(a_{2,0} = 0.05 + 0.40 u\), others 0, `seed=5`, 100 stars.
- Stage-2 must recover \(c_{00}, c_{10}\) within tolerance; \(c_{01}\) consistent with 0.

### C10.3.6 `combo_low_order`

- Defocus quadratic: \(0.1 + 0.2 u + 0.1 v + 0.15 (u^2+v^2)\)
- Astig: \(a_{2,2}=0.08\), \(a_{2,-2}=0.05\) constant
- Coma: \(a_{3,1}=0.12 v\), \(a_{3,-1}=0.12 u\)
- Seeing: Moffat α=1.1 px, β=2.5
- Diffusion 0.3, jitter 0.15 px
- 120 stars, `seed=6`

### C10.3.7 `extraction_stress`

- Same truth as `unaberrated` but sky=800 ADU, 40 stars, `seed=7`.
- Gates C1A coverage, not coefficient recovery (coefficients ~0).

## C10.4 Ground-truth records

For each star, a JSON row: `star_id`, `true_xy_px`, `true_field_xy_mm`, `true_theta` (dict of term_id → value), `true_flux_adu`.

File: `corpus/<scenario_id>/truth.parquet` + `image.fits` + `manifest.json`.

## C10.5 Scoring inequalities (fitter)

After C1A + C5 + C6, using **matched** `star_id` via nearest extracted centroid within 0.5 px of truth; unmatched truth stars are ignored (up to 10% unmatched allowed except `extraction_stress`).

Let \(\hat a_s\) be stage-1 local coefficient, \(a_s^\star\) truth.

**Per-star, median over matched stars:**

| Scenario | Quantity | Median \(\lvert\hat a - a^\star\rvert\) SHALL be ≤ |
|---|---|---|
| `unaberrated` | every phase \(a_k\) | 0.04 waves |
| `single_defocus_const` | \(a_{2,0}\) | 0.05 waves |
| `single_defocus_neg` | \(\min(\lvert\hat a-(-0.35)\rvert,\lvert\hat a-0.35\rvert)\) | 0.05 waves |
| `single_coma_linear` | \(a_{3,1}\) | 0.05 waves |
| `defocus_plane` | \(a_{2,0}\) | 0.06 waves |
| `combo_low_order` | each enabled phase term | 0.08 waves |

**Stage-2:** \(\lvert \hat c_{ij} - c_{ij}^\star \rvert \le 0.05\) for `single_coma_linear` \(c_{00}, c_{10}\); \(\le 0.06\) for `defocus_plane` \(c_{00}, c_{10}\); \(\lvert \hat c_{01}\rvert \le 0.04\) for `defocus_plane`.

**Evaluator (C10.7):** at 9 field points (3×3 grid on the detector including axis), \(\max|\mathrm{PSF}_{\mathrm{eval}} - \mathrm{PSF}_{\mathrm{truth\ forward}}| / \max(\mathrm{PSF}_{\mathrm{truth}}) \le 0.05\) for `single_coma_linear` and `defocus_plane` after flux normalization of both to sum 1.

## C10.6 Extraction gates (not fitter)

- `n_selected ≥ 0.5 * n_truth` for all scenarios except `extraction_stress` (≥ 0.4).
- C1A.12 `empty_cells ≤ 3`, `design_cond_plane ≤ 1e6`. Corpus extraction uses `selection_mode=highest_snr` (L18).
- Median centroid error \(\lvert \hat x - x^\star \rvert \le 0.15\) px for `unaberrated`.

## C10.7 Evaluator self-consistency

C7.4 provenance inequality \(10^{-12}\) on a zero-kernel, integer-centered, in-field point.

### C10.7.1 Digest fixture

A committed `ImageMeta` + `PupilSpec` + `catalog_id` fixture SHALL produce a bit-stable `image_meta_digest` (C7.4.1). Changing RFC 8785 key order or hashing the mask as JSON is non-conformant.

## C10.8 Jacobian CI

C5.10 SHALL pass on `unaberrated` (one representative star) and `single_defocus_const` (one star), including `passed_unconstrained` when bounds are active.

## C10.9 Defocus-init diversity (unit-level, no full image)

A noiseless stamp generated with the C10.1 camera, `known_defocus_waves=0.3`, true fitted \(a_{2,0}=0\), all other \(a_k=0\), kernels omitted, SHALL satisfy \(|a_{2,0}^{\mathrm{init}}|<0.05\) under C3.5.1. This catches double-counting of C4.5; C10.1’s `known_defocus_waves=0` cannot.

## C10.10 What the corpus SHALL NOT do

- Use Tiny Tim, Zemax, or any external PSF renderer as truth.
- Place stars within 40 px of the edge.
- Enable `periodic_error` or `field_rotation` in v1 scoring (those modules have unit tests on `K` only, C3.6, not end-to-end recovery in v1).
